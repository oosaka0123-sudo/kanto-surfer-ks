## 目的

代表9地点について、実波の目視確認・人手波情報・予報データを混同せずに使うための情報源台帳。
この文書は「情報源が存在する」ことの確認用であり、他社映像・記事・数値の転載許可を意味しない。

## 共通ルール

- BCM / SurfPatrol は同一系統として1ソース扱い。
- BCMのライブカメラは会員向け機能を含むため、無料公開カメラとは別分類。
- 波伝説のスーパーライブは短時間閲覧可能な場合があっても、基本はサービス内ライブとして扱う。
- なみある？は独自ライブがある地点と、外部公式カメラを案内している地点を分ける。
- 自治体・観光協会・YouTube等の公開ライブは「公開目視ソース」として別分類する。
- 他社ライブ映像・画像・有料波情報を転載、再配信、保存ミラーしない。
- 自動取得を行う場合は、利用規約・robots・API提供有無を確認してから別途設計する。
- 旧サービスや終了カメラを現役扱いしない。更新日・直近配信実績が確認できるものを優先する。

## 推奨する裏取り順位

1. **公開・公式ライブ** — 無料で現況を視覚確認できる場合の第一候補。ただし代表点との距離・画角を必ず評価する。
2. **BCM / SurfPatrol** — 現況・ライブ・波専門スタッフ情報の基準の1つ。同一系統なので1票。
3. **波伝説** — 独立した波情報・ライブの比較軸。
4. **なみある？** — 独自ライブがある地点では目視軸として有効。ライブなし地点は波情報/ガイドとして扱う。
5. **Open-Meteo Marine / Weather** — KS側の自動予報・ランキング生成の機械データ基盤。他社点数のコピーではなく独自補正に使う。
