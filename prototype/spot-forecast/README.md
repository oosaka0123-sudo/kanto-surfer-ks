# Spot forecast UI preview

関東サーファー個別ページの予報セクションを、実データ接続前に確認するための静的プレビューです。

## 目的

- 時間別と週間を同じ操作感にする
- 左の項目名を固定し、右側の時刻/日付列だけ横スクロールする
- スマホで約3列を見せ、残りをスワイプする
- 週間を縦カード化しない
- UI側で未確定の週間代表値を作らない
- 欠損値を推測しない

## データ

`window.KANTO_FORECAST_DATA` を定義すると表示できます。

```js
window.KANTO_FORECAST_DATA = {
  hourly: [{
    time: "2026-09-14T12:00:00+09:00",
    weather_label: "晴れ",
    wave_height_m: 0.5,
    period_s: 7,
    wind_speed_ms: 3.2,
    wind_direction_label: "北東"
  }],
  weekly: [{
    date: "2026-09-14",
    weather_label: "晴れ",
    wave_height_m: 0.6,
    period_s: 8,
    wind_speed_ms: 4.1,
    wind_direction_label: "北"
  }]
};
```

上記は形式例であり、実際の予報値ではありません。本番では検証済みの公開用データだけを渡します。

## 未接続時

データがなければ、時刻/日付の列構造だけ作り、予報値は `--` と表示します。週間値を時間別から平均・最大化する処理はありません。

## 確認項目

- 時間別/週間タブをクリック・矢印キーで切り替えられる
- 横スクロールできる
- 左ラベル列が sticky
- 今日/現在時刻に近い列が強調される
- グラフは数値データがある場合のみ描画される
- 欠損値を捏造しない
