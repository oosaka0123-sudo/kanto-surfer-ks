# Spot forecast UI preview

関東サーファー個別ページの時間別予報・10日間の波・風予報UIと、公開用データ接続を確認するためのプレビューです。

## 表示

- 時間別: 左の項目名を固定し、右側の時刻列だけ横スクロールする（スマホで約3列を見せ、残りをスワイプ）
- 10日間: 日付／天気／モデル波高／風速／風向／判定の6列表（関西サーファーKS「10日間の波・風予報」UIを基準）
- 欠損値を推測せず、時間別は `--`、10日間は `—` を表示する

## 公開データ

既定では `data-src="../../data/public/kugenuma.json"` を読み込みます。
地点別JSONは `scripts/build_public_forecast.php` が正規化済みデータから生成します。

- 時間別: 直近48時間を2時間間隔
- 10日間（`daily`）: 今日から10日、05:00〜17:00 JSTの波高最小〜最大・風速平均・風速加重平均風向・11時天気。集約はすべて `build_public_forecast.php` 側で行い、UI側では平均・最大などを作らない
- 判定列は関東版Calibration完了まで `daily.rows[].judgment`（現在は `pending`／「検証中」）をそのまま表示する
- `weekly`（8日・12時代表値）はデータ互換のため生成を継続するが、画面には表示しない

`window.KANTO_FORECAST_DATA` を定義した場合は、テスト用の明示データとして `data-src` より優先します。
