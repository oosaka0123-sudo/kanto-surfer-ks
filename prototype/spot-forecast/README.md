# Spot forecast UI preview

関東サーファー個別ページの時間別・週間予報UIと、公開用データ接続を確認するためのプレビューです。

## 表示

- 時間別と週間を同じ操作感にする
- 左の項目名を固定し、右側の時刻/日付列だけ横スクロールする
- スマホで約3列を見せ、残りをスワイプする
- 週間を縦カード化しない
- 欠損値を推測せず `--` を表示する

## 公開データ

既定では `data-src="../../data/public/kugenuma.json"` を読み込みます。
地点別JSONは `scripts/build_public_forecast.php` が正規化済みデータから生成します。

- 時間別: 直近48時間を2時間間隔
- 週間: 8日分、各日12:00 JSTに最も近い時刻を代表値として採用
- UI側では週間平均・最大などを作らない

`window.KANTO_FORECAST_DATA` を定義した場合は、テスト用の明示データとして `data-src` より優先します。
